# Releases

Use this folder for release notes and optional packaged artifacts.

## Suggested pattern
For each released skill version, keep:
- a short release note markdown file
- optionally the packaged `skill.zip` used for deployment

Example:
- `releases/transcript-to-action-plan-email-v1.0.md`

## Rule
The repo source under `skills/` is always the master copy.
Any zip placed here is only a deployment artifact.
