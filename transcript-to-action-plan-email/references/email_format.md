# Email format and tone

## Required section headers
Use these section headers exactly (in this order):

1. Next Steps
2. Accomplishments Since Our Last Meeting
3. Notes
4. Relevant Links

## Subject line
Format:

SBDC Next Steps - <CLIENT ID CODE> - <CLIENT COMPANY NAME>

- If a client id code (e.g., "HO1024") is not available, use "Client ID".
- If company name is not available, use "Client Company".

## Greeting and intro
- Professional, no emojis.
- A short, warm opener consistent with the meeting tone.
- Mention the scheduling link lives in the signature block.

## Section content rules
### Next Steps
- Focus on what the client should do next.
- Use actionable checklist items.
- Prefer "Verb + object + how/where" (e.g., "Draft capability statement v1 using the attached template")

### Accomplishments Since Our Last Meeting
- Include milestones and notable progress since the prior meeting.
- Highlight any milestone(s) that match the list in milestones.md.
- If there were no clear accomplishments, include a short line such as "No new milestones reported since our last meeting." (avoid shaming tone).

### Notes
- Organized bullets.
- Include detailed mini-checklists for any process/method/tactic discussed.
- Capture key decisions, constraints, and assumptions.

### Relevant Links
- Include only links that were discussed or shared.
- Prefer: Title (if known) then the URL on the next line.
