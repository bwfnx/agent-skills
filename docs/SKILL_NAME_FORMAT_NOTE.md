# Skill Name Format Note

When creating or updating a skill, the `name` field in `SKILL.md` frontmatter must use the slug format `your-skill-name`.

Do not use spaces in the frontmatter `name` field.

Example:
- correct: `competitive-research-analyst`
- incorrect: `competitive research analyst`

This note was added after a packaging/install validation error for the competitive research analyst skill.
