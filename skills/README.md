# Skills Directory

This folder holds the editable source for each reusable skill.

## Standard pattern
Each skill should live in its own folder:
- `skills/<skill-slug>/`

Recommended contents per skill:
- `SKILL.md`
- `agents/openai.yaml`
- `README.md`
- `CHANGELOG.md`
- `scripts/` if needed
- `references/` if needed
- `assets/` only if necessary
