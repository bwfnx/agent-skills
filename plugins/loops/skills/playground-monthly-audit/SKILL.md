> **Schedule:** Monthly
> **Needs:** workspace files
> **Helper scripts (yours, not included):** extract-northfork-raw-pdfs.py, parse-raw-documents.py, raw-to-wiki-ingest.py, server.py, wiki-build.py

Run the monthly workspace audit. You must check all six areas below against the mounted workspace folder and write a structured report.

## Setup

- Read `{{WORKSPACE_ROOT}}/CLAUDE.md` for full context.
- Read `{{WORKSPACE_ROOT}}/_wiki-infrastructure/last-audit.md` if it exists — compare results to the previous audit and note any changes.
- The playground root is the user's connected folder (`{{WORKSPACE_ROOT}}/`). In bash it maps to `/sessions/*/mnt/{{WORKSPACE_ROOT}}/`.

## The Six Checks

### 1. Workstation Completeness
The four workstations are: `sbdc-advising`, `fnx-pearl-consulting`, `northfork-farm`, `personal`.
Each must contain: `wiki/`, `raw/`, `outputs/`, `CLAUDE.md`.
List which required items are present/missing per workstation. Flag missing items as FAIL.

### 2. Backup Count
Count files in `_backups/`. Target is ~40 total (~10 per wiki). Flag as WARNING if over 40 and suggest trimming the oldest.

### 3. DELETE/ Status
Count files in `DELETE/`. If files exist, flag as ACTION NEEDED — remind {{USER}} to sweep the folder.

### 4. Orphaned Folders
List all top-level directories. Compare against the known set (the four workstations, infrastructure folders like `_backups`, `_wiki-infrastructure`, `_wiki-ingest-log`, `_wiki-templates`, `_parsed`, `_archive`, dotfiles like `.git`, `.claude`, `.obsidian`, `.agents`, `.impeccable`, and known project folders like `Wiki Builds`, `Codex Playground`, `UNSORTED`, `docs`, `memory`, `wiki-interview`, `__pycache__`, `__tests__`, `fnx-pearl-website`, `maryland-sbdc-website`, `DELETE/`). Flag unknown directories as REVIEW.

### 5. Root File Hygiene
List all files (not directories) at playground root. Flag files without a YYYY-MM-DD date prefix as REVIEW, except known exceptions: `CLAUDE.md`, `MEMORY.md`, `ARCHIVE.md`, `TASKS.md`, `AGENTS.md`, `desktop.ini`, `.gitignore`, `{{WORKSPACE_ROOT}}/raw-to-wiki-ingest.py`, `{{WORKSPACE_ROOT}}/wiki-build.py`, `{{WORKSPACE_ROOT}}/parse-raw-documents.py`, `{{WORKSPACE_ROOT}}/extract-northfork-raw-pdfs.py`, `{{WORKSPACE_ROOT}}/server.py`, `start-dashboard.bat`, `dashboard.html`, `sbdc-home.html`, `Untitled.canvas`, `wiki-interview.skill`, `_wiki-ingest-state.json`, and any dotfile.

### 6. Wiki Article Counts
Count `.md` files in each `<workstation>/wiki/` directory. Report per-workstation and total. Compare to previous audit if available.
